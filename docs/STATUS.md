# رفيق الحفظ — حالة التنفيذ (فرع `redesign`)

آخر تحديث: بداية العمل. هذا الملف يسجّل ما نُفّذ وما اختُبر وما بقي، ليُكمل أي شخص من حيث توقّف العمل.

## خط الأساس قبل التعديل (النسخة المنشورة `bd9fa17`)
- التقنية: Vite + JavaScript عادي (بدون إطار) + GSAP + localStorage + Service Worker. لا خادم ولا حسابات.
- الاختبارات: 230 اختبار وحدة ناجحة، فحص إمكانية الوصول (axe) ناجح، 8 رحلات end-to-end ناجحة.
- Lighthouse (محاكاة شبكة بطيئة): الوصول 100، أفضل الممارسات 100، SEO 100، الأداء 77–86، CLS صفر تقريبًا.
- لا نشر ولا دفع إلى المستودع البعيد من هذا الفرع إلا بتوجيه صريح.

## الدفعة 1 — الموثوقية ونظام التصميم
- [x] حالة التخزين الحقيقية (`storageState`) وشريط «لم يُحفظ تقدّمك» مع التصدير وإعادة المحاولة.
- [x] استيراد «الكل أو لا شيء»، معاينة قبل الاستيراد، نقطة استرجاع قبل الاستبدال، منع تكرار الأسماء.
- [x] تأكيد وتراجع لتعليم السورة كاملة وإلغاء تعليم آية.
- [ ] نظام التصميم الجديد (ألوان، أيقونات SVG، مكوّنات).

## الدفعة 2 — الهيكل والصفحات الأساسية
- [ ] الصفحة التعريفية منفصلة عن واجهة التطبيق، تنقل سطح المكتب/الموبايل، «المزيد».
- [ ] البداية الأولى (٣ خطوات تنتهي بجلسة فعلية).
- [ ] لوحتي كشاشة «الخطوة التالية».
- [ ] المصحف وموضع الاستكمال لكل طفل والعلامات المرجعية والسور المثبتة.
- [ ] جلسة الحفظ والمشغّل (تكرار مقطع، صوت واحد في كل وقت).
- [ ] ركن الأهل كصفحة منظمة.

## الدفعة 3 — بقية الصفحات
- [ ] المراجعة (تقييم من ٣ درجات) والخطط (إعادة توزيع) والأذكار (تراجع) والألعاب والإنجازات والبحث والتقارير.

## الدفعة 4 — التحقق
- [ ] اختبارات الرحلات، الموبايل، الوصول، الصوت، دون اتصال، التحديثات.

## خارج النطاق الآن (توسعات لاحقة بمتطلباتها)
- التنقل بالأجزاء: يحتاج جدول حدود أجزاء من مصدر موثوق ومراجَع، وليس عندنا مصدر كهذا حاليًا (لا يُستنتج ولا يُؤلَّف).
- التصحيح الآلي للتلاوة، المزامنة السحابية، حسابات المعلمين، التنبيهات الحقيقية في الخلفية: تحتاج خادمًا أو خدمات خارجية.
